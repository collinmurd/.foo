# Ansible Configuration

This directory contains Ansible playbooks and roles for managing the groceries server infrastructure.

## Prerequisites

Install Ansible on your local machine:

```bash
# Ubuntu/Debian
sudo apt install ansible

# macOS
brew install ansible

# Or via pip
pip3 install ansible
```

## Setup

1. **Inventory is auto-generated by Terraform** - The `inventory.ini` file is automatically created when you run `terraform apply`
2. Update `roles/users/vars/main.yml` with your actual SSH public key for the groceries user
3. Test connectivity: `ansible groceries_servers -m ping`

**Note:** The inventory file is managed by Terraform and should not be edited manually. It will be regenerated on each `terraform apply`.

## Usage

### Run the complete playbook

```bash
cd ansible
ansible-playbook playbook.yml
```

### Run specific roles

```bash
# Only update nginx configuration
ansible-playbook playbook.yml --tags nginx

# Only update cron jobs
ansible-playbook playbook.yml --tags cron
```

### Check mode (dry run)

```bash
ansible-playbook playbook.yml --check
```

### Run from project root with dynamic inventory

```bash
cd /home/collin/projects/.foo
ansible-playbook -i ansible/inventory.ini ansible/playbook.yml
```

## Structure

```
ansible/
├── ansible.cfg           # Ansible configuration
├── inventory.ini         # Server inventory
├── playbook.yml          # Main playbook
└── roles/
    ├── packages/         # System packages
    ├── users/            # User management
    ├── docker/           # Docker installation
    ├── storage/          # Persistent data volume mount
    ├── firewall/         # Firewall rules
    ├── nginx/            # Nginx configuration
    └── cron_jobs/        # Cron job management
```

## Integration with Terraform

The inventory file is automatically generated by Terraform via the `local_file` resource in `iac/local.tf`.

**Workflow:**

```bash
# 1. Apply infrastructure changes
cd iac && terraform apply

# 2. Inventory is automatically updated at ../ansible/inventory.ini

# 3. Run Ansible to configure the server
cd ../ansible && ansible-playbook playbook.yml
```

**Optional: Automatic Ansible execution after Terraform**

If you want Ansible to run automatically after Terraform provisions infrastructure, add this to your Terraform code:

```hcl
resource "null_resource" "ansible_provision" {
  depends_on = [oci_core_instance.main, local_file.ansible_inventory]

  provisioner "local-exec" {
    command = "cd ${path.module}/../ansible && ansible-playbook playbook.yml"
  }

  triggers = {
    instance_id = oci_core_instance.main.id
    # Uncomment to re-run on any Ansible role changes:
    # roles_hash = sha256(join("", [for f in fileset("${path.module}/../ansible/roles", "**/*.yml") : filesha256("${path.module}/../ansible/roles/${f}")]))
  }
}
```
